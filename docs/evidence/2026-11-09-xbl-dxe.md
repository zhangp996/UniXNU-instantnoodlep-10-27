# OnePlus 8 Pro UEFI DXE extraction (2026-11-09)

The board's own UEFI drivers live in the xbl partition. A 5 MiB dump of
`/dev/block/by-name/xbl_a` (sdb1) is an ELF with one firmware volume at file
offset 0x87e30; that volume contains a compressed inner FV with 93 PE32 DXE
modules.

Commands:

```sh
adb shell su -c "dd if=/dev/block/by-name/xbl_a of=/sdcard/unixnu/xbl_a.img bs=4096"
# uefi_firmware (1.16): FirmwareVolume(data[0x87e30:]) -> FirmwareFileSystem
# -> FirmwareFile -> UI/PE32/DXE_DEPEX sections
```

Each directory keeps `<name>.efi`, `<name>.depex` (when present) and an EDK2
`<name>.inf` with the file GUID from the firmware volume. The set is copied to
`D:\新建文件夹\instantnoodlep-dxe` and will populate
`Binaries/instantnoodlep` of the firmware platform.

Not yet extracted: the RawFiles set the display driver reads (panel XML,
BDS menu, battery provision) and the ACPI tables; both live in other partitions.
